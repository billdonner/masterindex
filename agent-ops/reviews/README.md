# reviews/

Cross-repository review/adjudication artifacts, for cases where a review
doesn't belong inside the target repository itself. Empty until such a
review happens.

Prefer writing a repository's own review artifacts
(`review-same-system.md`, `review-cross-system.md`,
`review-comparison.md`) inside that repository's
`docs/agent-bootstrap/` (or its established equivalent) per
`../AGENT-BOOTSTRAP.md`. Use this directory only when material genuinely
spans repositories or has no sensible home in a single target repo.
