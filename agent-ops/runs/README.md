# runs/

Per-repository orchestration run records. Empty until a standardization
run (see `../PROCESS.md`) actually happens for some repository in the
portfolio.

Suggested layout when a run starts: `runs/<repo>-<date>/` containing the
classification, inspection notes, and a pointer to where that
repository's own `docs/agent-bootstrap/` artifacts live.

Do not pre-populate this directory with speculative run data.
