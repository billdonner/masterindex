# Bootstrap Kit

This folder contains the exact reusable text for injecting MasterIndex behavior into other places.

## Files

- `MASTERINDEX_UNIVERSAL_INJECTION.md` — preferred single file for injecting MasterIndex everywhere except `workin On`
- `AGENTS_SNIPPET.md` — drop-in text for `AGENTS.md`
- `masterindex-bootstrap-skill/SKILL.md` — personal Codex skill starter
- `housekeeping-task-template.md` — starter prompt for periodic tasks

## Intent

These files are for hand injection elsewhere, without forcing structural changes in this workspace.

## Preferred starting point

If you only want one file to inject broadly, use:

- `MASTERINDEX_UNIVERSAL_INJECTION.md`

The other files are still useful, but that one is the simplest portable baseline.
